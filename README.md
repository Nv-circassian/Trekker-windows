# Трекер для Windows 11 (64 бит)

Нужен Node.js (LTS) с nodejs.org. Папку держите в пути без русских букв, например `D:\trekker-windows`.

## Запуск для проверки
Откройте папку проекта в Проводнике, в адресной строке напишите `cmd` и нажмите Enter. В чёрном окне:

    npm install
    npm start

Первая команда качает много файлов (несколько минут). Вторая открывает окно Трекера.

## Сборка установщика
    npm run build

Готовый установщик появится в папке `dist`: `Трекер Setup 1.0.0.exe`. Запустите его, выберите папку установки, и приложение появится в меню «Пуск» и на рабочем столе.

## Автосохранение
По умолчанию файл копии пишется в `Документы\Трекер\trekker-backup.json` и перезаписывается через пару секунд после каждого изменения. Другой файл можно выбрать в «Настройки» → «Автосохранение в файл». Если папка «Документы» синхронизируется с OneDrive, копия сама попадёт в облако.

Данные приложения хранятся на этом компьютере. Для переноса используйте «Сохранить копию» и «Восстановить из копии» в настройках.

## Если что-то не так
- Windows пишет «Защитник Windows предотвратил запуск»: нажмите «Подробнее», затем «Выполнить в любом случае». Установщик не подписан, поэтому предупреждение нормально.
- Ошибка про symbolic link при сборке (она нужна для иконки приложения): включите Параметры, Для разработчиков, Режим разработчика, или запустите cmd от имени администратора и повторите `npm run build`.
- Сборка зависла надолго: подождите 5-10 минут, она скачивает Electron и инструменты установщика.
